Anthropic Daily · 2026-05-08

Anthropic 今日聚焦 SDK 迁移：Skill 配置 API 全面废弃并转向更细粒度的 skills 选项；Claude Code 强化工作区与沙箱配置能力。

Claude SDK 重大变更：Skill 配置 API 正式废弃

**Python SDK (v0.1.77) 和 TypeScript SDK (v0.2.133) 同步废弃 `'Skill'` 在 `allowedTools` 中的用法**，推荐改用 `ClaudeAgentOptions` 上的 `skills` 选项。 **这意味着什么**： - 开发者需要迁移现有代码，新项目应直接使用 `skills` 配置 - `skills` 选项提供更细粒度的技能控制能力 - 外部集成 Claude Agent 的应用需尽快完成迁移以保持兼容性 **其他改进**：Python SDK 优化了错误信息——此前错误结果仅返回通用 "Command failed with exit code 1"，现在会显示具体错误文本（如 "Reached maximum number of turns"），与 TypeScript SDK 行为一致
claude-agent-sdk-python v0.1.77 claude-agent-sdk-typescript v0.2.133

Claude Code v2.1.133：工作区与沙箱配置增强

**新增 `worktree.baseRef` 设置**：支持选择新 worktree 从 `origin/` (默认 `fresh`) 还是本地 `HEAD` 创建。注意：默认行为变更可能影响已有工作流。 **Linux/WSL 新增托管设置**：`sandbox.bwrapPath` 和 `sandbox.socatPath` 允许指定自定义路径。 **这意味着什么**：使用 worktree 功能或 agent-isolation 的团队需注意默认行为变化；自定义沙箱路径能力便于企业内网环境部署
claude-code v2.1.133

内部工具链更新（connect-rust / buffa）

`connect-rust` v0.4.1-v0.4.2：新增 mTLS identity 示例、stream 优化、Bug 修复。 `buffa` v0.5.0-v0.5.2：优化 zero-copy 序列化、修复 lint 规则、提升 CI 流程安全性。 **说明**：均为内部基础设施更新，无面向外部用户的功能变化
