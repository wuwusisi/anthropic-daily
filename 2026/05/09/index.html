Anthropic Daily · 2026-05-09

Anthropic SDK 生态全面支持 Managed Agents 多 Agent 协作能力，PHP/CLI/TS 多语言同步更新；Claude Code 修复 Windows 兼容性问题并增强 auto mode 安全策略；新增金融行业示例仓库。

SDK 生态更新

Anthropic 多语言 SDK 同步更新，核心变化： - **PHP SDK v0.18-0.20**：三连更版本，新增 Managed Agents API 支持（multiagents、outcomes、webhooks、vault validation），以及 Workload Identity Federation、interactive OAuth 和 auth profiles - **CLI v1.7.0**：同步支持上述 Managed Agents 新能力 - **TypeScript SDK v0.2.136**：新增 `resolveSettings()` alpha 功能，可直接读取 MDM 配置而不启动 CLI；正式弃用 `TodoWrite` tool，未来将迁移至 Task tools（`TaskCreate`/`TaskGet`/`TaskUpdate`/`TaskList`） **这意味着什么**：多语言 SDK 对 Managed Agents 的统一支持标志着 Anthropic 在企业级 Agent 部署能力上趋于成熟。webhooks + vault validation 的组合让多 Agent 协作在生产环境中的可靠性大幅提升。Task tools 的引入为更结构化的任务管理铺路，开发者应开始规划从 TodoWrite 到 Task tools 的迁移路径。

Claude Code 桌面端更新

v2.1.136 & v2.1.137 更新要点： - **Windows 兼容性修复**：VS Code 扩展在 Windows 上的激活失败问题已解决 - **autoMode 增强**：新增 `settings.autoMode.hard_deny` 配置，允许设置无论用户意图或 allow exceptions 都强制阻断的分类规则 - **配置稳定性修复**：MCP servers 在 `.mcp.json`、插件和 claude.ai connectors 中的配置不会再在 `/clear` 后消失 - **企业反馈收集**：新增 `CLAUDE_CODE_ENABLE_FEEDBACK_SURVEY_FOR_OTEL` 环境变量，支持企业通过 OpenTelemetry 捕获用户体验反馈 **这意味着什么**：`hard_deny` 的引入让 auto mode 的安全策略更加精细，企业可对敏感操作设置不可绕过的防护底线。配置持久化问题的修复对依赖 MCP 集成的开发者是重要的稳定性提升。
