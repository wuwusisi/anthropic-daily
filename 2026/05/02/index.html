Anthropic Daily · 2026-05-02

Anthropic 发布 Agent Skills 框架并更新 SDK 的 Managed Agents API，标志着其 Agent 生态建设进入新阶段；今日无重大产品发布或商业化动态。

Agent 开发工具

Anthropic 发布了 **skills** 公开仓库，这是一个面向 Agent 的 Skills（技能）框架。作为 PM，这意味着： - 开发者可能很快会有标准化的方式来为 Claude Agent 扩展自定义能力 - 这可能是 Anthropic 构建 Agent 生态系统的第一步，后续可能出现 Skills 市场或官方技能库 同时，**anthropic-sdk-typescript v0.92.0** 改进了 **Managed Agents API**，支持更灵活的 header 配置。这为企业在自有基础设施上部署和管理 Claude Agent 提供了更好的集成能力。
