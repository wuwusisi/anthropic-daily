**Claude Code v2.1.131/132** 带来多项实用改进： - 🐛 **Windows 平台关键修复**：VS Code 扩展激活问题已解决（`createRequire` polyfill bug），Mantle 端点认证问题修复 - 🔧 **环境变量控制**：新增 `CLAUDE_CODE_SESSION_ID` 传递至 Bash 子进程，便于 Hooks 追踪；新增 `CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN=1` 选项禁用全屏渲染，保持终端原生滚动历史 - 📎 **剪贴板体验优化**：Ctrl+V 粘贴图片时显示 "Pasting…" footer 提示 **这意味着什么**：对在 Windows 环境使用 Claude Code 的开发者，这是一次关键的稳定性提升；环境变量增强让 Hooks 调试和会话追踪更便捷。

SDK 层面：错误处理精细化与权限 API 完善

**Python SDK v0.1.76** 重点更新： - ✅ **API 错误状态可追踪**：`ResultMessage` 新增 `api_error_status` 字段，直接暴露 HTTP 状态码（429、500、529 等），便于日志分类和错误监控 - ✅ **权限建议反序列化修复**：`ToolPermissionContext.suggestions` 现正确返回 `PermissionUpdate` 实例而非原始 dict **这意味着什么**：生产环境中调用 Claude API 时，开发者现在可以更精准地识别和处理限流、服务器错误等问题，提升 Agent 应用的健壮性。
