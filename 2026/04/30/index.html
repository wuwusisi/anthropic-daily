Anthropic Daily · 2026-04-30

Anthropic 发布 anthropic-cli v1.4.0 优化 Managed Agents API，同时新推 financial-services-plugins 仓库，加速 Claude 在金融行业垂直场景的生态布局。

开发者工具更新

**anthropic-cli v1.4.0** 于 2026-04-28 发布，主要更新集中在 **Managed Agents API** 的功能改进。这意味着开发者可以通过更完善的 API 接口来构建和管理 AI Agent，提升了构建复杂 Agent 应用的开发效率。
anthropic-cli v1.4.0 Release

金融行业插件生态

Anthropic 官方 GitHub 新增 **financial-services-plugins** 仓库，表明 Anthropic 正在构建面向金融行业的插件/集成方案。这可能预示着 Claude 在金融领域的应用扩展，包括合规检查、风险分析、交易辅助等场景的定制化支持。对于 PM 而言，这意味着 Claude 的行业落地正在加速，后续可能有更多垂直领域的解决方案。
